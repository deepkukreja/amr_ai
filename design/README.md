# Robot Buildworks product theme

The Robot Buildworks website is the visual reference for final AMR interfaces. Its brand layer is `work/robot-buildworks-website/public/brand.css` in the shared AMR workspace. In a source-only checkout, use the matching website version or the [shared theme tokens](robot-buildworks-theme.css) beside this guide.

Use the same palette, type family, border treatment, focus style, and approved Robot Buildworks wordmark across the final website, fleet and teleoperation dashboard, and any model-training or perception interface selected for delivery. Import the small shared stylesheet into final interfaces. Use approved brand assets from the website's source. If the website's theme changes, update the shared tokens with it so the other final surfaces consume the same values.

Adapt layout and density to each surface. The dashboard can use denser controls and tables while keeping the same visual language. Keep alarm, stale-data, and motion status easy to distinguish with text or icons alongside color. Preserve each surface's accessible contrast, focus, and control states.

Spend design and visual review time on interfaces selected for release. Keep test screens, temporary demos, internal diagnostic views, and training tools functional and lightweight. Run the functional checks needed for the change and skip visual polish for those surfaces.
