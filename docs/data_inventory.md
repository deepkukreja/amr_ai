## Before using or sharing a dataset

For each dataset, document the original source, access instructions,
license or data usage agreement, annotation format, class definitions,
preparation procedure, and train/development/test split.

Distinguish raw datasets from generated derivatives. Do not assume that
two similarly named variants contain the same images or annotations.

For evaluation, preserve held-out test data and document whether any
benchmark has already influenced model selection or threshold tuning.
