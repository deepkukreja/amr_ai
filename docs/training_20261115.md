# Local model continuation — 15 November 2026

Completed a 21-epoch fine-tune of the existing YOLO26s person/rider detector,
starting from `runs/experiments/indian_road_manual280_lowlr_v1/weights/best.pt`.
Early stopping retained epoch 11. The new checkpoint is
`runs/experiments/indian_manual280_continue_20261115/weights/best.pt`.

The new candidate did not improve the established 166-image development
benchmark, so the earlier model remains the reference. No deployed detector
or ROS motion configuration was changed.

person/rider confidence 0.15/0.25, and class-aware one-to-one matching at
IoU 0.50. The benchmark is development data already used for selection;
it is not an untouched final test. These freshly measured counts can
differ slightly from historical tables with other inference settings.

between the 166 development images and the audited road-model ancestry.
